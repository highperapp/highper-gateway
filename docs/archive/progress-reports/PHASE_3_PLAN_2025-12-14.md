#### Task 5: ModSecurity SecRule Parser (10-15 hours)
**Goal**: Parse and execute ModSecurity rule syntax

**Files to Modify**:
- `src/middleware/waf/modsecurity_engine.rs` - SecRule parser
- `src/middleware/waf/rule_parser.rs` (new) - Rule syntax parser
- `src/middleware/waf/rule_executor.rs` (new) - Rule execution engine

**SecRule Syntax Support**:
```
SecRule REQUEST_URI "@rx \.\./" "id:1,phase:1,deny,status:403,msg:'Path Traversal'"
SecRule ARGS "@rx <script" "id:2,phase:2,deny,status:403,msg:'XSS Attack'"
```

**Implementation Steps**:
1. Lexer for SecRule syntax
2. Parser for variables, operators, actions
3. Rule compilation and optimization
4. Chained rule support
5. Transformation functions (lowercase, urlDecode, etc.)
6. Load from .conf files

**Variables to Support**:
- REQUEST_URI, ARGS, REQUEST_HEADERS, REQUEST_BODY
- RESPONSE_HEADERS, RESPONSE_BODY
- REMOTE_ADDR, REQUEST_METHOD

**Operators to Support**:
- @rx (regex), @streq (string equals), @contains
- @validateByteRange, @validateUrlEncoding
- @pm (parallel matching)

## 3.3: API Aggregation Enhancement (20-30 hours)

### Current State

**Existing Files**:
- `src/gateway/aggregation/executor.rs` - Basic aggregation
- `src/gateway/aggregation/merger.rs` - Simple merging

### Tasks Breakdown

#### Task 1: Full JSONPath Implementation (15-20 hours)
**Goal**: Implement complete JSONPath spec (RFC 9535)

**Features to Implement**:
1. **Basic Selectors** (3-4 hours)
   - Root (`$`)
   - Child (`.field`, `['field']`)
   - Recursive descent (`..`)

2. **Array Operations** (4-5 hours)
   - Index (`[0]`, `[-1]`)
   - Slice (`[0:5]`, `[::2]`)
   - Wildcard (`[*]`)

3. **Filters** (5-7 hours)
   - Comparison (`?(@.price < 10)`)
   - Regex (`?(@.name =~ /pattern/)`)
   - Existence (`?(@.field)`)
   - Logical operators (`&&`, `||`, `!`)

4. **Functions** (3-4 hours)
   - `length()`, `min()`, `max()`
   - `avg()`, `sum()`
   - Custom functions

**Files to Create**:
- `src/gateway/aggregation/jsonpath/` (new module)
  - `parser.rs` - JSONPath parser
  - `executor.rs` - Path execution
  - `filter.rs` - Filter evaluation

---

#### Task 2: Custom Template Merge (5-10 hours)
